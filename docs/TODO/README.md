## Rules

1. **When an item is done and its validation passed, delete it** from `PENDING.md` (and its checks from `VALIDATION.md`). Do not leave ticked or struck-through items behind; git history is the record.
2. Put a new item in `PENDING.md` the moment it is discovered, with a priority, the affected files and what "done" means.
3. When a file is empty, delete it. When this folder is empty, delete the folder.
4. Scope reminder: personal use, free tiers by default, no PRO plan or billing, mobile deferred (see `../README.md`).
